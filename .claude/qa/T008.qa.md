1. `docker compose up -d redis`
   Expect: output shows `Container redis  Started` (or `Created`/`Started` on first run).
2. `docker compose ps redis`
   Expect: `STATUS` column shows `Up ... (healthy)` within about 10-15 seconds (healthcheck `start_period` is 10s, `interval` 10s).
3. `docker exec redis redis-cli ping`
   Expect: `PONG`.

   Expect: `maxmemory` / `268435456` (this is 256MB in bytes — confirms `redis.conf` was actually loaded, not stock defaults).
5. `docker exec redis redis-cli CONFIG GET maxmemory-policy`
   Expect: `maxmemory-policy` / `allkeys-lru`.
6. `docker exec redis redis-cli CONFIG GET save`
   Expect: `save` / `` (empty string — persistence disabled).
