## Manual QA — T014

**Prerequisites:** Docker Desktop running; `src/infra/.env` exists (copy from `.env.example` and set `SA_PASSWORD` if not already present — required even to build `api-gateway` alone, since Compose parses the whole file).

1. From `src/infra`, run:
   ```
   docker compose build api-gateway
   ```
   Expect: build completes with `api-gateway  Built` (or `unpacking to ... done` on first build) — no red error output.

2. Run:
   ```
   docker compose up -d api-gateway
   ```
   Expect: `Container api-gateway  Started`.

3. Run:
   ```
   docker compose ps api-gateway
   ```
   Expect: `STATUS` column shows `Up ... (healthy)` within ~40 seconds (the compose file's `start_period: 40s`). If it shows `(unhealthy)` or `(health: starting)` indefinitely, that's a regression of the exact bug this ticket fixed.

4. Run:
   ```
   curl -i http://localhost:8080/health
   ```
   Expect: `HTTP/1.1 200 OK`, `Content-Length: 0` — empty body, no stack trace or environment leakage.

5. **Bypass-scope check (the important one)** — confirm the `/health` exemption did NOT accidentally open up a real protected route. Run:
   ```
   curl -i http://localhost:8080/user/profile
   ```
   Expect: `HTTP/1.1 401 Unauthorized` with a JSON body shaped `{"code":"INVALID_TOKEN","message":"Missing or malformed Authorization header.","traceId":"..."}`. If this instead returns `200` or forwards to user-service, the JWT bypass has leaked scope — stop and escalate, do not proceed to `/push`.

6. Also confirm method-scoping on the bypass itself:
   ```
   curl -i -X POST http://localhost:8080/health
   ```
   Expect: `401 Unauthorized` (only `GET /health` is exempt — a `POST` to the same path must still require a token).

7. Check image size:
   ```
   docker image inspect shareconnectsave/api-gateway:dev --format="{{.Size}}"
   ```
   Expect: a number under `200000000`. (Reference measurement taken during this review: `95654906`.)

**Cleanup:**
```
docker compose stop api-gateway
docker compose rm -f api-gateway
```
(Or `docker compose down` if no other stack services are running that you need to keep.)
