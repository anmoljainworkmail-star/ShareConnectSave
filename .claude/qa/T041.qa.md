## Manual QA — T041

**Prerequisites:** Docker Desktop running; `docker-up` completed (SQL Server reachable); JDK 21 on PATH; run all commands from `src/services/rating-service`.

1. From `src/infra`, confirm infra is up:
   ```
   docker compose ps
   ```
   Expect: `sqlserver` shows `healthy`, `sqlserver-init` shows `Exited (0)`.

2. Export the required env vars (bare `mvn spring-boot:run` does not pick up a profile by itself):
   ```
   set SPRING_PROFILES_ACTIVE=dev
   set RATING_DB_PASSWORD=<the sa password from your .env>
   ```
   Leave `RATING_DB_HOST`/`PORT`/`NAME` unset unless your compose mapping differs.

3. Run the service:
   ```
   mvn spring-boot:run
   ```
   Expect: log lines showing Flyway applying `V001__rating_service_initial_schema.sql`, followed by `Tomcat started on port 8080`.

4. Confirm health:
   ```
   curl http://localhost:8080/actuator/health
   ```
   Expect: exactly `{"status":"UP"}`.

5. Confirm Flyway actually applied `V001` and the enum columns are plain strings: connect to SQL Server (e.g. via `sqlcmd` or Azure Data Studio) against the rating service DB and run:
   ```sql
   SELECT * FROM flyway_schema_history;
   SELECT * FROM ratings;       -- should exist and be empty
   SELECT * FROM trust_scores;  -- should exist and be empty
   ```
   Expect: one row in `flyway_schema_history` for version `1`, `success = 1`; both tables exist with the indexes from V001.

6. Confirm idempotent restart: stop the service (Ctrl+C), run `mvn spring-boot:run` again. Expect: no checksum-mismatch or re-apply error — Flyway logs that the schema is already current.

**Not covered here (by design):** automated persistence round-trip tests (saving a `Rating`/`TrustScore` row and reading it back, confirming `badge_level`/`request_limit` are stored as literal strings) are deferred to T083 (Integration Tests: Java/Testcontainers — Discovery, Connection, Rating), batched across all three services, not written per-ticket.

**Cleanup:** Stop the running process (Ctrl+C). Optionally `docker compose down` from `src/infra` if the infra isn't needed for anything else.
