1. `docker compose -f src/infra/docker-compose.yml -f src/infra/docker-compose.override.yml up -d --build admin-service` — Expect: build completes with no errors; in particular watch for the `shared-java-lib` install step ("BUILD SUCCESS") before admin-service's own `mvnw package` runs. Failure looks like: `COPY failed: file not found` (context misconfigured) or `Could not resolve dependencies for project admin-service... com.shareconnectsave:shared-java-lib:jar:0.0.1-SNAPSHOT` (shared-java-lib install step skipped or failed).
2. `docker compose -f src/infra/docker-compose.yml ps admin-service` — Expect: `STATUS` column shows `healthy` (may show `starting` for up to the `start_period: 60s` window first). Failure looks like: `unhealthy` or the container repeatedly restarting.
3. `curl http://localhost:8088/actuator/health` — Expect: HTTP 200 with JSON body including `"status":"UP"` and (since `show-details: always`) nested `mongo`, `kafka`, and `circuitBreakers` components also `UP`/`CLOSED`. Failure looks like: connection refused (port not published) or a component reporting `DOWN`.

Expect: result under 300 MB. **Already confirmed: 134999010 bytes (~135MB)** — lighter than every prior Java service's image, as predicted for the no-SQL-Server/JPA HTTP-only packaging shape. Do **not** read this number off `docker images` — confirmed on this machine to over-report by ~3x.
5. `docker exec admin-service sh -c "java -version"` — Expect: reports a JRE (not JDK) version string, confirming the runtime stage truly has no compiler toolchain. A `javac` check (`docker exec admin-service sh -c "which javac"`) should return nothing / exit non-zero, confirming the JDK didn't leak into the runtime stage.
6. Confirm no stale SQL dependency: `docker compose -f src/infra/docker-compose.yml config | grep -A5 "admin-service:"` (or open the rendered config) — Expect: `depends_on` lists only `mongodb` and `kafka`, no `sqlserver`/`sqlserver-init`.

**Cleanup:** `docker compose -f src/infra/docker-compose.yml down admin-service` (or `docker compose down` for the full stack if nothing else needs to stay up).
